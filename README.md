# dotfiles
Collection of some of my commonly used dotfiles/configs

In MacOS, set Caps Lock to function as Control, Key Repeat to fast

Uncheck font smoothing in general settings

Set Appearance > Text highlight color to Other... `#4d699b` (Kanso Pearl `pearlBlue4`):
`defaults write -g AppleHighlightColor "0.301961 0.411765 0.607843 Other"`

## Kanso Pearl file locations
- `kanso_pearl.conf` → `~/.config/ghostty/themes/kanso_pearl.conf`
- `claude-kanso-pearl.json` → `~/.claude/themes/kanso-pearl.json`
- `claude-settings.json` → `~/.claude/settings.json`
- `lazygitconfig.yml` → `~/Library/Application Support/lazygit/config.yml`
